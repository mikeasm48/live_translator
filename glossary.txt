# Словарь терминов uz -> ru для Live Translator.
#
# Формат: одна пара на строку, "исходный текст = перевод".
# "#" — комментарий. "!" в начале строки просит точное совпадение словоформы,
# но это возможность нейроглоссариев, и для узбекского она может быть
# проигнорирована — обычные пары работают всегда.
#
# Лимиты Yandex Translate: не более 50 пар и 20 000 символов суммарно.
# Файл перечитывается на ходу — можно дописывать термины прямо во время встречи.
#
# ГЛАВНОЕ ПРАВИЛО, проверенное на практике:
# добавляйте пару, только если перевод без неё НЕВЕРЕН, а не просто непривычен.
# Словарь вмешивается в разбор предложения, и лишняя пара ломает смысл фразы.
# Особенно опасны многословные пары с глаголами ("deploy qildik = задеплоили"):
# они склеивают соседние части предложения. Односложные термины безопасны.
#
# Каждую новую пару проверяйте на живой фразе:
#   java -jar target/live-translator.jar --try="Bugun deploy qildik, testlar o'tdi"
# Если строка "со словарём" стала хуже строки "без словаря" — пару убрать.
